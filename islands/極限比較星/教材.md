## 教材內容

### 規則與不規則比較級／最高級變化

在進行人事物比較時，須依字彙音節決定變化方式：
1. 單音節字尾直接加 -er / -est（tall → taller → tallest）；單音節且字尾為「短母音＋單子音」時先重複字尾（big → bigger → biggest）；「子音＋y」結尾須去 y 改 ier / iest（easy → easier → easiest）。
2. 多數雙音節與三音節以上形容詞，於字前加 more / the most（careful → more careful → the most careful）。
3. 必考不規則變化：
   • good / well → better → best
   • bad / badly / ill → worse → worst
   • many / much → more → most
   • little → less → least（表「較少」，只修飾不可數名詞；可數名詞的少要用 few → fewer → fewest！）
   • late → later（較晚）／the latest（最新的）vs. the last（最後的／上一回）
   • far → farther / farthest（距離更遠）vs. further / furthest（程度進一步）

### 原級、比較級與最高級四大必考句型

1. 原級同等比較：「A ＋ be/V ＋ as ＋ 形容詞／副詞原級 ＋ as ＋ B」表兩者一樣；否定為 not as/so...as。
2. 比較級五大黃金構造：
   • 基本式：「比較級 ＋ than」（可數少：fewer ＋ 複數名詞 ＋ than；不可數少：less ＋ 不可數名詞 ＋ than）。
   • 加強語氣：只可用 much / even / far / a lot / a little 修飾比較級，絕對不可用 very！
   • 愈來愈…：「比較級 and 比較級」（getting better and better，越來越好了）。
   • 愈…就愈…：「The ＋ 比較級..., the ＋ 比較級...」（The harder you study, the higher grades you will get.）。
   • 比較級表達最高級：「比較級 ＋ than any other ＋ 單數名詞」（比其他任何一個都更…）。
3. 最高級用法：「the ＋ 最高級 ＋ of all / in ＋ 團體範圍」；若要說「最…之一」，使用「one of the ＋ 最高級 ＋ 複數名詞」！注意比較「兩者之間哪個較…」用「the ＋ 比較級 ＋ of the two」。
