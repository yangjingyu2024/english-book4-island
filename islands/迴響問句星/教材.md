## 教材內容

### 附加問句四大黃金基本原則

附加問句加在直述句尾端，用來向對方確認「…對嗎？／…是不是？」。解題照著這四個步驟絕不失分：
1. 前肯後否、前否後肯（極性相反）：前句是肯定敘述，後面用否定縮寫（isn't / doesn't / didn't / won't / can't，注意附加問句的否定詞一律需縮寫！）；前句是否定敘述，後面改用肯定（is / does / did）。
2. 動詞與時態一致：
   • 前句有 be 動詞（am / is / are / was / were），直接沿用對應 be 動詞。
   • 前句有情態助動詞（can / will / should / would）或現在完成式（have / has ＋ Vpp），直接沿用助動詞。
   • 前句為一般動詞（包含 have to ＋ VR「必須」、have a party 等一般實義用法！），必須派出助動詞 do / does / did。小陷阱：put / cut / read 三態同形，主詞為第三人稱單數且動詞卻沒加 s 時（He read the book），代表它是過去式，附加問句要用 didn't he!
3. 主詞一律改寫為「人稱代名詞」：只准出現 I, you, he, she, it, we, they（例外只有 There is / are... 保留 there：There is a park nearby, isn't there?）。若前句主詞為 this / that 或動名詞／不定詞片語，後面全部改寫為 it；these / those 改寫為 they！
4. 隱形否定詞警告：直述句中只要出現 never（從不）、seldom（很少）、hardly（幾乎不）、few / little（極少，注意不可有 a）、nothing / nobody / no one 時，整個前句已屬否定，後面附加問句必須用「肯定」！

### 五大特殊附加問句與「事實導向」答法

除了四大原則之外，以下五種特殊開頭在國中段考與會考出現頻率極高，建議直接秒記：
1. Let's ＋ VR..., shall we?（邀請「我們一起…」固定配 shall we?）
2. 一般祈使句（包含 Don't... 與 Let us ＋ VR...）, will you?（肯定祈使句可用 will / won't you，否定祈使句只可用 will you?，測驗選 will you 最穩當！）
3. I am..., aren't I?（因沒有 amn't I 的縮寫，固定配 aren't I?；但否定 I am not..., am I? 照正常用 am I!）
4. Everyone / Everybody / Someone / Nobody 當主詞：後面接「they」！（例：Nobody called this morning, did they?）；若是 Everything / Nothing 指事物時，後面改用「it」！
5. 回答附加問句以「事實是做過還是沒做」決定 Yes/No，千萬別被中文翻譯「對／不是」牽著走！只要事實「是肯定（對，他有去）」就答 Yes, he did.；只要事實「是否定（沒有，他沒去）」就答 No, he didn't.
